# 💜 Cofre Secreto – Jogo de Senha 🪻

O **Cofre Secreto** é um projeto desenvolvido com HTML, CSS e JavaScript. O desafio é descobrir a combinação correta de três números para conseguir desbloquear o cofre. 🌸

## 💜 Objetivo do jogo

Acertar a senha numérica e conseguir abrir o cofre. Para isso, o jogador pode utilizar as dicas disponíveis durante a partida. 🪻

## 💜 Instruções

1. Informe três números, um em cada campo.
2. Clique em **Tentar Abrir** para verificar se a combinação está correta.
3. Use o botão **Ver Dica** para receber uma informação sobre o primeiro número da senha.
4. Caso queira fazer outra tentativa, clique em **Limpar**.

## 💜 Configuração da senha

A combinação atual do jogo é `6, 7, 2`.

Você pode modificar a senha diretamente no arquivo `script.js`, alterando o vetor:

```javascript
const senhacofre = [6, 7, 2];
```

A senha deve conter três números inteiros de 0 a 9.

## 💜 Organização dos arquivos

O projeto está dividido em três arquivos principais:

- **index.html:** contém os campos, textos e botões do jogo.
- **style.css:** responsável pelas cores, organização e visual da página.
- **script.js:** controla as tentativas, verifica a senha, mostra as dicas e limpa os campos.

## 💜 Executando o projeto

Para jogar, basta:

1. Baixar os arquivos do projeto.
2. Colocar todos os arquivos na mesma pasta.
3. Abrir o `index.html` em um navegador.

Não precisa instalar nenhum programa adicional. 🌸

## 💜 Disponibilizando o jogo online

O projeto também pode ser publicado gratuitamente usando o GitHub Pages:

1. Entre no repositório do projeto.
2. Acesse **Settings → Pages**.
3. Escolha a opção **Deploy from a branch**.
4. Selecione `main` e `/ (root)`.
5. Clique em **Save**.

Depois da publicação, o GitHub disponibilizará um link para acessar o jogo.
